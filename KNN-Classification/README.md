# KNN Classification

## 📌 Overview

This project demonstrates the implementation of the K-Nearest Neighbors (KNN) algorithm for a classification task using the Iris dataset.

## 📊 Dataset

* Iris Dataset
* Features: Sepal length, Sepal width, Petal length, Petal width
* Target: Flower species (Setosa, Versicolor, Virginica)

## ⚙️ Steps Performed

1. Data Loading
2. Train-Test Split
3. Feature Scaling
4. Model Training using KNN
5. Prediction
6. Evaluation using:

   * Accuracy
   * Confusion Matrix
   * Classification Report

## 📈 Results

* Achieved high accuracy on test data
* Confusion matrix shows correct classification across all classes

## 🚀 How to Run

```bash
pip install numpy pandas scikit-learn matplotlib seaborn
python knn.py
```

* Importance of feature scaling in KNN
* Effect of K value on model performance
* Understanding classification evaluation metrics
